# ModelTrace — Apresentação (Projeto NoSQL)

Site de apresentação (slides navegáveis, `←` `→` ou clique nas laterais) das 6 atividades
da entrega de NoSQL do projeto **ModelTrace**: modelagem documental, CRUD, aggregation
pipelines, Redis (comum + probabilístico) e grafo de conhecimento com Neo4j Graph Data
Science.

Publicado via GitHub Pages a partir deste repositório (`main`, raiz).

Código-fonte completo do projeto: [github.com/DiegoXavier-hub/ModelTrace](https://github.com/DiegoXavier-hub/ModelTrace)
— o pipeline NoSQL em si fica em [`rec/pipeline/`](https://github.com/DiegoXavier-hub/ModelTrace/tree/main/rec/pipeline).

Este repositório é apenas o site estático da apresentação (por isso é separado do
repositório principal — evita "git dentro de git").
